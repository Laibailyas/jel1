JEL1 Gut & Glow landing page

Plain HTML, CSS and JavaScript. No React, build tools or package installation required.

Open index.html in a browser. The product photography and Glacial Indifference font files are included in this folder. Lora loads from Google Fonts when an internet connection is available; Georgia is the local fallback.

Included interactions: responsive mobile navigation, hover/click mega menus, working formula tabs with keyboard support, section search, scroll reveals, flavour and journal sliders, and a waitlist email form.

The waitlist form opens an email draft addressed to contact@jel1.com with the visitor's email prefilled. It does not store signups automatically; connect a mailing-list provider or server endpoint for automatic collection.

The konjac research spotlight links to the cited primary studies and labels the human trial's cohort and limits. The conceptual gel visual is an illustration, not a study image or JEL1 product result.
